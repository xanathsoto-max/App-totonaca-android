#Aprende Totonaco - App Android Nativa

App Android desarrollada por hablante nativa de Totonaco para preservación de lengua indígena.

Stack: Java | Android Studio | SQLite | XML | Offline-first

Características:
- 4 módulos educativos con 50+ palabras y audio nativo
- Base de datos local SQLite - funciona 100% sin internet
- Diseño accesible para niños y adultos mayores (8-70 años)
- Enfoque intercultural y preservación lingüística
Impacto: Primera app de su tipo creada desde la comunidad.

Autora: Xanath Soto Simon - Puebla, México
Tesis: Desarrollo de aplicación móvil
